# Resource review and integration decisions

Reviewed 18 October 2026 before feature implementation. The later implementation brief is the controlling specification: exact-price approval per bundle, structured business/product data, three connectors first, and no shared PayPal task-budget mandate. The earlier architecture remains background context where it does not conflict.

## Free hosting update — 19 October 2026

The zero-spend requirement supersedes the original paid web/worker/Postgres Blueprint and OpenAI runtime. Gemini Interactions REST now provides structured requirement extraction, bounded offer selection and cited answer drafts with an explicit free-model allowlist, shared database-backed request allowance and no paid fallback. Live calls require a Free Tier key.

Render uses one Free web service and Neon Free storage. The database queue is drained within the web process after relevant authenticated activity and verified webhooks; hourly protected maintenance recovers work after restarts. Optional ten-minute liveness pings make no database query. GitHub schedules can be delayed and Render hours are shared across all free services.
